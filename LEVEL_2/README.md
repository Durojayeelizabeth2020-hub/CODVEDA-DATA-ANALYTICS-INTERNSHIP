# Task 1: Regression Analysis - Stock Price Prediction

## Level
Level 2 (Intermediate)

## Description
Perform a simple linear regression analysis to predict stock prices based on historical data.

## Objectives
- Split the dataset into training and testing sets
- Fit a linear regression model using scikit-learn
- Interpret the coefficients of the model
- Evaluate the model using metrics such as R-squared and Mean Squared Error

## Tools Used
- **Language**: Python
- **Libraries**: pandas, numpy, scikit-learn, matplotlib, seaborn
- **Environment**: Jupyter Notebook

## Files
1. **2) Stock Prices Data Set.csv** - Historical stock price data
2. **Cleaned data.ipynb** - Data cleaning and preprocessing
3. **linear_regression_evaluation.csv** - Model evaluation results
4. **stock_linear_regression_model.pkl** - Saved trained model
5. **stock_prediction_results.csv** - Predicted vs actual results

## How to Run
1. Open notebooks in Jupyter
2. Run `Cleaned data.ipynb` first, then `linear_regression_evaluation`
